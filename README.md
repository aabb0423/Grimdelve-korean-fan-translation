# Grimdelve 한국어 패치

[English](README.en.md)

Grimdelve의 Windows Steam판을 위한 비공식 한국어 패치입니다. 원작 게임을 설치한 뒤 적용할 수 있습니다. [Steam 상점](https://store.steampowered.com/app/3616480/Grimdelve/)

## 다운로드 및 설치

**Windows Steam판 빌드 `26858035`**용입니다. 설치에는 Windows 기본 기능만 사용합니다.

1. 게임을 종료하고, 저장소의 **Releases**에서 `Grimdelve_Korean_Patch.zip`을 받습니다.
2. ZIP 안의 파일과 폴더를 원하는 위치에 함께 풉니다.
3. **`Install_Grimdelve_Korean.bat`**를 더블클릭합니다. Steam 라이브러리에서 Grimdelve를 찾아 한글 패치를 자동으로 설치합니다.
4. 설치가 끝나면 Steam에서 게임을 실행하고 **설정 → 언어 → 한국어**를 선택합니다.

게임 폴더를 찾지 못하면 Steam 라이브러리에서 Grimdelve를 우클릭하고 **관리 → 로컬 파일 보기**를 선택합니다. `Game.exe`가 있는 폴더에 ZIP을 풀고 배치파일을 실행해 주세요.
