# Grimdelve Korean Patch

[한국어](README.md)

This is an unofficial Korean localization patch for the Windows Steam edition of Grimdelve. Install the base game before applying the patch. [Steam store page](https://store.steampowered.com/app/3616480/Grimdelve/)

## Download and install

The patch supports **Windows Steam build `26858035`**. The installer uses only built-in Windows tools.

1. Close the game and download `Grimdelve_Korean_Patch.zip` from this repository's **Releases**.
2. Extract all files and folders from the ZIP to a location of your choice.
3. Double-click **`Install_Grimdelve_Korean.bat`**. The installer finds Grimdelve in your Steam libraries and applies the patch automatically.
4. Once installation is complete, launch the game through Steam and select **Settings → Language → 한국어 (Korean)**.

If the installer cannot find the game, right-click Grimdelve in your Steam library and select **Manage → Browse local files**. Extract the ZIP into the folder containing `Game.exe` and run the batch file there.

## What's included

- 7,892 translated text entries, including dialogue, choices, menus, and item descriptions
- 22 localized images, including the title screen, selection screens, journal, cipher note, and decoding chart
- 26 Korean subtitles for the opening cinematic, with the original English narration

## Report translation or display issues

Please report translation mistakes or display issues in this repository's **Issues**. Include the scene, the text shown on screen, and your patch version so the line is easier to find. Attach a screenshot if you have one.
